# AHVAÉ Studios

A cinematic portfolio for film, photography and creative direction.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS 4
- Motion for React
- Lenis smooth scrolling

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment

No environment variables are required for the public portfolio experience. Booking uses a mailto fallback to `ahvaestudios@gmail.com` until a transactional email provider is configured.
